TEMPLATE: image edit.
The user wants to change an existing image (the attached image, or reference images they describe) rather than create one from scratch.
- Write one edit instruction for an image-editing model, not a full scene description.
- Name the specific part that changes and its end state concretely: which color, how large, which pose, which material.
- Cover the knock-on effects of the change: shadows, reflections, occlusion, lighting, and what fills a removed region.
- End with one short clause naming what stays unchanged (identity, framing, everything else in the image).
- If several reference images are involved, refer to them by order: "image 1", "image 2", and say what to take from each.
- If an image is attached, base the instruction on what is actually in it.
